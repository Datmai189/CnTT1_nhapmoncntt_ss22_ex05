1. Vấn đề là gì?
Thành viên hỏi lỗi Docker, xung đột cổng thiếu tổ chức, khiến thông tin bị trôi và câu hỏi bị lặp lại.
2. Yêu cầu đề bài
Tạo mẫu Bug Report và quy trình ba bước để thành viên tự xử lý lỗi trước khi hỏi nhóm.
3. Cách làm
Bug Report:
- Context: Môi trường và thao tác gây lỗi.
- Expected: Kết quả mong muốn.
- Actual: Kết quả thực tế.
- Log: Thông báo lỗi đầy đủ, đã xóa thông tin bí mật.
Quy trình:
1. Tìm lỗi trên Google.
2. Tra GitHub Issues, Stack Overflow và tài liệu nội bộ.
3. Nhờ AI giải thích, sau đó kiểm chứng trước khi chạy lệnh.
Nếu vẫn chưa sửa được, gửi Bug Report đầy đủ lên nhóm.
